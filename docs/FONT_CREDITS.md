글꼴 파일은 포함하지 않습니다. 네이버 한글한글아름답게의 NanumSquare Neo 배포본에서 다음 파일을 구해 저장소 루트에 놓으세요.

- NanumSquareNeo-bRg.ttf
- NanumSquareNeo-cBd.ttf
- NanumSquareNeo-dEb.ttf
- NanumSquareNeo-eHv.ttf

게임 본문은 ExtraBold, 이미지 렌더러는 명세에 따라 Bold·ExtraBold·Heavy 등을 사용합니다. 원본 게임의 글꼴 리소스는 사용자가 준비한 ISO에서 추출합니다.
