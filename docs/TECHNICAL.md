# 기술 설명

PROJECT.BIN의 PACK 항목을 원래 크기 안에서 수정합니다. 문장은 게임의 16비트 글자 코드로 인코딩하며, 필요 구간은 빈 슬롯에 재배치하고 포인터를 갱신합니다. 폰트 팩에는 KS X 1001 한글 2,350자를 배치합니다.

이미지는 PSMT8/PSMT4 팔레트 인덱스 및 원래 스위즐 형식을 유지합니다. 새로 검수한 항목은 `mode: exact`로 자동 상자 확장·배경 추정을 우회합니다. `box`는 지울 범위, `text_box`는 글자를 배치할 범위입니다. `ink_ramp`·`edge_ramp`는 팔레트 인덱스로 글자·테두리를 직접 지정합니다. `base_tile`은 원본의 빈 버튼을 복제합니다.

일시정지 메뉴 컨트롤러 세 항목의 기존 좌표는 원본의 85픽셀 메뉴 칸과 어긋나 있었습니다. 구종명에는 전체 팔레트 RGBA 양자화가 잘못된 색·배경 인덱스를 선택하는 문제가 있었습니다. RGB가 일정한 팀 이름은 명도가 아닌 투명도 인덱스가 글자 형태를 나타냅니다.

validation의 결과는 바이너리·텍스처 검증입니다. 게임 실행 화면·전체 진행 검증을 대신하지 않습니다. 패치 적용 뒤 이전 세이브스테이트를 불러오면 이전 텍스처·실행파일 메모리가 복구될 수 있습니다.
