# 석세스 모드 스크립트 번역 규칙 (translation/RULES.md 도 먼저 읽을 것)
입력 translation/script/jobs/NNN.jsonl: {"id","jp","cap","w"} → 출력 translation/script/out/NNN.jsonl: {"id","ko"} 모든 id.
- 이 대사는 게임 스크립트 안에 **같은 길이로** 들어간다. `cap` = 최대 코드 수(글자·공백·태그·줄바꿈 각각 1, `{FFE8:xxxx}` 는 2). **절대 초과 금지.** 짧으면 자동으로 공백이 채워진다.
- 태그는 **개수·순서 그대로** 유지: `{FC01}` `{FC03}` (대기/다음 페이지), `{FC05}`~`{FC0F}` (색 시작/끝), `{F0xx}` (주인공 이름 등 변수), `{F1xx}` (표정), `{FFE8:xxxx}` (이름 등 변수). 태그 앞뒤 문장이 자연스럽게 이어지도록 어순을 조정한다.
  - `{F010}`, `{F003}` 등 F0xx 는 이름/변수 자리 → 뒤 조사는 받침 무관하게(`{F010}의`, `{F010}에게`) 또는 문장을 바꿔 피한다.
- `\n` 은 대사창 줄바꿈. 한 줄 최대 25칸(태그 제외 글자 수). 줄은 어절 경계에서.
- 캐릭터 말투 유지. 주요 인물: 矢部(야베, 말끝 「でヤンス」→「~양스」 예: 気持ち悪いでヤンス → 징그럽양스), パワプロ=파워프로, 監督=감독, 彼女=여자친구. 인물 이름은 기존 번역(translation/out/*.jsonl, translation/glossary.tsv)에서 grep 해 통일.
- 선택지(「はい」「いいえ」 등 cap 이 작은 것)는 짧게: 예/아니오.
- 의성어·감탄은 자연스러운 한국어로. 일본어·한자 남기지 말 것(KS X 1001 한글만).
- 완료 후 `python tools/check_script.py NNN` 오류 0건까지.
